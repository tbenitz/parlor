# Parlor

A private two-seat table: chess, checkers, tic-tac-toe, or battleship against another person.

Chat and moves travel peer-to-peer after a short handshake. Camera and mic are optional. No accounts.

**Play:** https://tbenitz.github.io/parlor/

**Repo:** https://github.com/tbenitz/parlor

## How to play

1. Open the live page.
2. One person hosts and copies the table code.
3. The other joins with that code.
4. Pick a game. Camera stays off unless you tap the icons.

## GitHub Pages

This repo is a static site. Pages should serve from the `main` branch, `/` (root).

If the live URL 404s, turn Pages on once:

Settings → Pages → Source: Deploy from a branch → `main` / `/` (root) → Save.
